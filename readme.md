# Rossmann Tool Box Redesign

## Overview
This repository contains the redesign project for Rossmann Toolbox. It modernizes the [rossmann-toolbox](https://github.com/labstructbioinf/rossmann-toolbox) model with improved embedding and updated dependencies with to work with python 3.12. Another aim of this project is to incorporate functionality for structure based prediction which was not available in the previous model.
